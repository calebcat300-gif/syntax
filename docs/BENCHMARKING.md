# Benchmark policy

Do not present predictions, theoretical bandwidth ceilings or synthetic traces as measured token speeds.

For each real benchmark, record the model and revision, quantization format, GPU/CPU, driver/CUDA/compiler versions, memory capacity, batch size, prompt and output lengths, context length, concurrency, TTFT, decode tokens/sec, total wall time and output quality/reference.

Use representative prompts, warmups, repeated measurements, correctness checks and comparable model settings between Syntax and baselines such as SGLang.
