# Contributing to Syntax

Syntax is at an experimental stage. Focused fixes, tests, profiling notes and technical research are welcome.

- Make small, reviewable changes with explanatory commit messages.
- Keep credentials, model weights and local caches out of Git.
- Add correctness tests before presenting speed improvements.
- Don't force new languages or services into the architecture without a concrete need.
- When sharing a benchmark, include model revision, quantization, hardware, driver/toolchain versions, prompt lengths, batch size, context, and measurement procedure.
- Clearly label synthetic simulations, theoretical bandwidth bounds, and real generation tests separately.
